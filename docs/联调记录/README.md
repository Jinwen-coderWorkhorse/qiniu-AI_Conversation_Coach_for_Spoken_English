# 联调记录

本目录用于工程师 E 维护跨模块联调问题、接口字段变更和冒烟测试记录。

## 使用规则

- 本地依赖环境（MySQL / RabbitMQ / MinIO）启动见 [E-02-本地依赖环境启动说明.md](E-02-本地依赖环境启动说明.md)。
- API 字段变更先同步 `packages/contracts/openapi.json`，再在本目录记录影响范围。
- 联调问题需要标明负责人、状态和复现路径。
- SSE 只记录进度事件问题；最终结果字段以 REST 契约为准。
- 不记录完整 transcript、音频签名 URL、匿名 secret、provider key 等敏感信息。

## 问题记录模板

```md
## YYYY-MM-DD 问题标题

- 状态：待处理 / 处理中 / 已修复 / 已关闭
- 负责人：A / B / C / D / E
- 影响接口或页面：
- 复现步骤：
- 期望结果：
- 实际结果：
- 处理结论：
```
