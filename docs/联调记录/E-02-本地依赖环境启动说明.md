# E-02 本地依赖环境启动说明

编写日期：2026-06-07  
负责人：工程师 E  
适用范围：MySQL、RabbitMQ、MinIO 本地依赖；API / Worker / Web 仍在宿主机运行。

## 1. 前置条件

| 工具 | 版本建议 | 说明 |
|---|---|---|
| Docker Desktop / Docker Engine | 20.10+ | 用于启动依赖服务 |
| Docker Compose | v2+ | 已内置于 Docker Desktop |
| Git | 任意 | 克隆仓库 |

> 本 PR 不包含 API、Worker、Web 容器化；后续 E 系列任务再扩展一键启动应用进程。

## 2. 一次性准备

```bash
# 1. 进入仓库根目录
cd qiniu-AI_Conversation_Coach_for_Spoken_English

# 2. 复制环境变量模板
cp .env.example .env

# 3. 按需修改 .env（默认已与 docker-compose 凭据对齐，一般无需改动）
```

## 3. 启动依赖服务

```bash
docker compose -f infra/docker-compose.yml up -d
```

等待所有服务 healthy 后，可执行：

```bash
docker compose -f infra/docker-compose.yml ps
```

期望状态：

| 服务 | 容器名 | 端口 | 用途 |
|---|---|---|---|
| mysql | ai-coach-mysql | 3306 | 业务数据库 |
| rabbitmq | ai-coach-rabbitmq | 5672 / 15672 | 报告任务队列 / 管理台 |
| minio | ai-coach-minio | 9000 / 9001 | S3 兼容对象存储 / 控制台 |
| minio-init | ai-coach-minio-init | — | 一次性创建私有 bucket |

### 3.1 默认凭据（仅本地开发）

| 组件 | 账号 | 密码 / Key |
|---|---|---|
| MySQL root | root | root |
| MySQL 应用库 | coach / conversation_coach | coach_dev |
| RabbitMQ | coach | coach_dev |
| MinIO | minioadmin | minioadmin |

管理入口：

- RabbitMQ 管理台：<http://127.0.0.1:15672>
- MinIO 控制台：<http://127.0.0.1:9001>

## 4. 验证依赖可用

```bash
# MySQL
docker exec ai-coach-mysql mysqladmin ping -h 127.0.0.1 -uroot -proot

# RabbitMQ
docker exec ai-coach-rabbitmq rabbitmq-diagnostics -q ping

# MinIO bucket
docker run --rm --network host minio/mc:RELEASE.2024-12-18T13-15-44Z \
  sh -c "mc alias set local http://127.0.0.1:9000 minioadmin minioadmin && mc ls local/conversation-coach-media"
```

## 5. 停止与清理

```bash
# 停止服务（保留数据卷）
docker compose -f infra/docker-compose.yml down

# 停止并删除数据卷（慎用，会清空本地库和对象）
docker compose -f infra/docker-compose.yml down -v
```

## 6. 与应用进程的关系

当前 E-02 只保证**依赖中间件**可启动。应用侧建议顺序：

1. 启动本节 Docker Compose。
2. 工程师 A：执行 DB migration / seed（依赖 `DATABASE_URL`）。
3. 工程师 B：按需将 `REPORT_WORKER_MODE` 切换为 `async` 并接入 RabbitMQ。
4. 工程师 C/D：启动 `apps/web`（`npm run dev`）。
5. 工程师 A/B：启动 `apps/api`（`uvicorn`）。

`.env.example` 中的 `DATABASE_URL`、`RABBITMQ_URL`、`S3_*`、`JWT_SECRET`、`AI_PROVIDER` 已与 Compose 默认值对齐，其他工程师可直接复制 `.env` 使用。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 3306 / 5672 / 9000 端口被占用 | 修改 `infra/docker-compose.yml` 左侧宿主机端口映射，并同步更新 `.env` |
| MySQL 首次启动较慢 | 等待 healthcheck 通过；`docker compose ps` 显示 healthy 后再连库 |
| Windows 路径问题 | 在 Git Bash / PowerShell 中均使用 `-f infra/docker-compose.yml` 相对路径 |
| Docker 未安装或未启动 | 先安装 Docker Desktop；无法运行时可用 `docker compose config` 做静态语法校验 |
