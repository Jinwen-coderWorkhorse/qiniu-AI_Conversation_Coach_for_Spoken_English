# 核心逻辑流程图

简单 CRUD 不单独画图。本文件只覆盖 MVP 中状态多、链路长、异常分支多的功能。

## 1. 单轮语音对话链路

```mermaid
sequenceDiagram
  participant User as 用户
  participant Web as Web App
  participant API as FastAPI Router
  participant UC as Use Case
  participant Conv as Conversation Orchestrator
  participant Media as Media Service
  participant ASR as ASR Client
  participant Session as Practice Session Service
  participant LLM as LLM Client
  participant TTS as TTS Client
  participant DB as MySQL
  participant Store as S3/MinIO

  User->>Web: 按住说话
  Web->>Web: RecordRTC 录音和波形反馈
  User->>Web: 松开发送
  Web->>API: POST /practice-sessions/{id}/user-turns
  API->>UC: submit_user_audio(command)
  UC->>Conv: transcribe_user_audio(command)
  Conv->>Media: 保存用户音频
  Media->>Store: 上传用户音频对象
  Conv->>ASR: 识别音频
  ASR-->>Conv: transcript + confidence + metrics
  Conv->>Session: 创建 pending user turn
  Session->>DB: 写入 conversation_turns
  API-->>Web: 返回 transcript 和 needs_retry
  Web->>User: 展示识别文本，确认或重说

  User->>Web: 确认 transcript
  Web->>API: POST /practice-sessions/{id}/turns/{turn_id}/confirm
  API->>UC: confirm_user_turn(command)
  UC->>Conv: generate_ai_reply(command)
  Conv->>Session: 标记 user turn confirmed，读取上下文
  Conv->>LLM: 生成角色内回复
  LLM-->>Conv: AI text
  Conv->>TTS: 合成语音
  TTS-->>Conv: AI audio
  Conv->>Media: 保存 AI 音频
  Media->>Store: 上传 AI 音频对象
  Conv->>Session: 创建 confirmed AI turn，推进步骤
  Session->>DB: 写入 AI turn
  API-->>Web: 返回 AI text + audio_url + current_step_no
```

关键规则：

- `/user-turns` 只完成 ASR 和 pending user turn 创建。
- `/confirm` 才进入 LLM / TTS。
- `client_turn_id` 保证上传幂等。
- 重复 confirm 返回已有 AI turn，不重复调用 provider。
- SSE 只推送进度，最终结果以 REST 响应或查询接口为准。

## 2. ASR 低置信与重说流程

```mermaid
flowchart TD
  A["用户松开发送音频"] --> B["ASR 返回 transcript 和 confidence"]
  B --> C{"confidence < 0.65?"}
  C -->|是| D["创建 pending turn<br/>needs_retry=true"]
  D --> E["前端提示建议重说"]
  E --> F{"用户选择"}
  F -->|重说| G["POST discard<br/>turn=discarded"]
  G --> A
  F -->|仍确认| H["POST confirm<br/>低置信进入报告降权"]
  C -->|否| I{"0.65 <= confidence < 0.8?"}
  I -->|是| J["创建 pending turn<br/>标记 low_confidence"]
  J --> H
  I -->|否| K["创建 pending turn<br/>正常确认"]
  K --> H
```

关键规则：

- 低置信不是默认 HTTP 错误，前端仍能展示 transcript。
- `confidence < 0.65` 默认建议重说，不进入评分。
- 用户强行确认低置信内容时，报告生成要降权并标记低置信。

## 3. 结束练习与报告生成链路

```mermaid
sequenceDiagram
  participant Web as Web App
  participant API as Practice Router
  participant EndUC as end_session_use_case
  participant Session as Practice Session Service
  participant ReportRepo as Report Repository
  participant Queue as RabbitMQ
  participant Worker as Celery Worker
  participant Assess as Assessment Service
  participant LLM as LLM Client
  participant DB as MySQL

  Web->>API: POST /practice-sessions/{id}/end
  API->>EndUC: end_session_and_enqueue_report(command)
  EndUC->>Session: 校验 ownership 和状态
  EndUC->>DB: 事务开始
  EndUC->>Session: session.status = reporting
  EndUC->>ReportRepo: 创建 pending report
  EndUC->>DB: 事务提交
  EndUC->>Queue: 发布 report job(session_id, report_id)
  API-->>Web: 返回 report_id 和 reporting

  Queue-->>Worker: 消费 report job
  Worker->>DB: 读取 confirmed user turns 和 AI turns
  Worker->>Assess: 计算 speech metrics 和低置信降权
  Assess->>LLM: 生成结构化报告 JSON
  LLM-->>Assess: JSON
  Assess->>Assess: Pydantic schema 校验
  Assess->>DB: 写入 scores、feedback_json、status=completed
  Worker-->>Web: SSE report.ready
```

失败处理：

| 失败点 | 处理 |
|---|---|
| 重复结束 session | 返回已有 report_id |
| 无 confirmed 用户 turn | 返回 `CONFLICT`，不创建报告 |
| LLM JSON 不合法 | 最多重试 2 次 |
| 重试后仍失败 | `assessment_reports.status=failed`，保留 transcript |
| SSE 断开 | 前端轮询 `GET /practice-sessions/{id}/report` |

## 4. 会话状态机

```mermaid
stateDiagram-v2
  [*] --> in_progress: 创建练习
  in_progress --> in_progress: 上传/确认/重说 turn
  in_progress --> reporting: 结束练习
  in_progress --> aborted: 用户放弃或超时无报告
  in_progress --> failed: 主链路异常不可恢复
  reporting --> completed: 报告生成成功
  reporting --> failed: 报告生成失败
  completed --> [*]
  aborted --> [*]
  failed --> [*]
```

状态约束：

| 状态 | 允许操作 |
|---|---|
| `in_progress` | 上传用户语音、确认 turn、废弃 turn、结束练习 |
| `reporting` | 查询练习详情、查询报告、订阅 SSE；不允许继续提交 turn |
| `completed` | 查询历史、查询报告、再练一次 |
| `aborted` | 查询历史，报告可能不存在 |
| `failed` | 查询错误状态，可根据场景提供重试 |

## 5. 前端对话页状态机

```mermaid
stateDiagram-v2
  [*] --> loadingOpening
  loadingOpening --> aiSpeaking
  aiSpeaking --> ready
  ready --> recording: 按住
  recording --> uploading: 松开
  uploading --> transcribing
  transcribing --> transcriptReview
  transcriptReview --> recording: 重说
  transcriptReview --> aiThinking: 确认
  aiThinking --> aiSpeaking
  aiSpeaking --> ready
  ready --> ending: 结束练习
  ending --> reporting
  reporting --> reportReady
  uploading --> error
  transcribing --> error
  aiThinking --> error
  aiSpeaking --> error
  error --> ready: 重试
  reportReady --> [*]
```
