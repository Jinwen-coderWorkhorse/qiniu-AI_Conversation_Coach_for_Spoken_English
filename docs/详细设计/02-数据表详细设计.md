# 数据表详细设计

## 1. 全局表设计约定

| 项 | 约定 |
|---|---|
| 数据库 | MySQL 8.x |
| 存储引擎 | InnoDB |
| 字符集 | `utf8mb4` |
| 排序规则 | 优先 `utf8mb4_0900_ai_ci`；低版本 MySQL 使用 `utf8mb4_unicode_ci` |
| 主键 | 业务记录使用应用层 UUID 字符串；固定场景使用稳定 `slug` |
| 时间字段 | `created_at`、`updated_at` 使用 `datetime(3)`；API 输出 ISO 8601 |
| 软删除 | 可被用户删除或下架的数据使用 `deleted_at datetime(3) null` |
| 分表 / 分区 | MVP 不做分表、不做分区 |
| JSON 字段 | 仅用于场景步骤、ASR metrics、报告详情等结构差异大的 MVP 数据 |

MVP 保留 5 张表：`users`、`scenarios`、`practice_sessions`、`conversation_turns`、`assessment_reports`。

## 2. `users` 匿名用户表

| 字段名 | 数据类型 | 长度 | 是否主键 / 非空 | 默认值 | 注释 | 索引 |
|---|---:|---:|---|---|---|---|
| id | varchar | 36 | 主键、非空 | 应用生成 UUID | 内部用户主键 | 主键索引 |
| anonymous_id | varchar | 64 | 非空 | 无 | 前端本地保存的设备级匿名 ID | 唯一索引 `uk_users_anonymous_id` |
| anonymous_secret_hash | varchar | 255 | 非空 | 无 | 匿名 secret 哈希，后端不保存明文 | 无 |
| created_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 创建时间 | 无 |
| updated_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 更新时间 | 无 |
| deleted_at | datetime(3) | - | 可空 | `NULL` | 软删除时间 | 无 |

必要约束：

- `anonymous_id` 全局唯一。
- 恢复匿名身份时必须同时校验 `anonymous_id` 和 `anonymous_secret_hash`。
- 查询业务数据时必须过滤 `deleted_at is null`。

## 3. `scenarios` 固定场景配置表

| 字段名 | 数据类型 | 长度 | 是否主键 / 非空 | 默认值 | 注释 | 索引 |
|---|---:|---:|---|---|---|---|
| slug | varchar | 64 | 主键、非空 | 无 | 场景稳定标识：`interview` / `restaurant` / `meeting` | 主键索引 |
| name | varchar | 64 | 非空 | 无 | 场景展示名 | 无 |
| summary | varchar | 512 | 非空 | 无 | 一句话说明 | 无 |
| estimated_minutes | int | - | 非空 | 5 | 预计练习分钟数 | 无 |
| user_role | varchar | 64 | 非空 | 无 | 用户角色 | 无 |
| ai_role | varchar | 64 | 非空 | 无 | AI 角色 | 无 |
| opening_message | text | - | 非空 | 无 | AI 开场白 | 无 |
| system_prompt | text | - | 非空 | 无 | 场景系统提示词 | 无 |
| steps_json | json | - | 非空 | 无 | 有序步骤数组 | 无 |
| sort_order | int | - | 非空 | 0 | 首页展示顺序 | 无 |
| created_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 创建时间 | 无 |
| updated_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 更新时间 | 无 |
| deleted_at | datetime(3) | - | 可空 | `NULL` | 软删除时间，用于场景下架 | 无 |

必要约束：

- MVP 只 seed 3 条记录，不提供后台新增。
- `steps_json` 结构必须包含 `step_no`、`title`、`prompt_goal`、`completion_rule`。
- 首页排序数据量极小，`sort_order` 不单独建索引。

## 4. `practice_sessions` 练习会话表

| 字段名 | 数据类型 | 长度 | 是否主键 / 非空 | 默认值 | 注释 | 索引 |
|---|---:|---:|---|---|---|---|
| id | varchar | 36 | 主键、非空 | 应用生成 UUID | 练习会话主键 | 主键索引 |
| user_id | varchar | 36 | 非空 | 无 | 所属匿名用户 | 索引 `idx_practice_sessions_user_created`、`idx_practice_sessions_user_status` |
| scenario_slug | varchar | 64 | 非空 | 无 | 练习场景 slug | 外键索引 |
| status | varchar | 32 | 非空 | `in_progress` | `in_progress` / `reporting` / `completed` / `aborted` / `failed` | 索引 `idx_practice_sessions_status_updated`、`idx_practice_sessions_user_status` |
| current_step_no | int | - | 非空 | 1 | 当前步骤序号 | 无 |
| ended_at | datetime(3) | - | 可空 | `NULL` | 结束时间 | 无 |
| created_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 创建时间，历史列表排序使用 | 索引 `idx_practice_sessions_user_created` |
| updated_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 更新时间，异常会话排查使用 | 索引 `idx_practice_sessions_status_updated` |
| deleted_at | datetime(3) | - | 可空 | `NULL` | 软删除时间，删除历史时使用 | 无 |

必要索引：

| 索引名 | 字段 | 说明 |
|---|---|---|
| `idx_practice_sessions_user_created` | `(user_id, created_at)` | 历史记录列表 |
| `idx_practice_sessions_status_updated` | `(status, updated_at)` | 查找超时或失败会话 |
| `idx_practice_sessions_user_status` | `(user_id, status)` | 创建练习时检查是否已有 `in_progress` |

必要约束：

- 同一用户同时只允许 1 个 `in_progress` session，由应用层在事务内校验。
- `scenario_slug` 必须存在于 `scenarios.slug`。
- 删除历史时只软删除 session，同时软删除关联 turn 和 report。

## 5. `conversation_turns` 对话轮次表

| 字段名 | 数据类型 | 长度 | 是否主键 / 非空 | 默认值 | 注释 | 索引 |
|---|---:|---:|---|---|---|---|
| id | varchar | 36 | 主键、非空 | 应用生成 UUID | 发言主键 | 主键索引 |
| session_id | varchar | 36 | 非空 | 无 | 所属练习会话 | 唯一索引 `uk_conversation_turns_session_turn_index`、索引 `idx_conversation_turns_session_speaker` |
| turn_index | int | - | 非空 | 无 | 会话内顺序号 | 唯一索引 `uk_conversation_turns_session_turn_index` |
| speaker | varchar | 16 | 非空 | 无 | `user` / `ai` | 索引 `idx_conversation_turns_session_speaker` |
| step_no | int | - | 非空 | 1 | 发言发生时的步骤 | 无 |
| status | varchar | 32 | 非空 | `pending` | `pending` / `confirmed` / `discarded` / `failed` | 无 |
| client_turn_id | varchar | 64 | 可空 | `NULL` | 前端生成的上传幂等 ID | 唯一索引 `uk_conversation_turns_session_client_turn` |
| content_text | text | - | 非空 | 无 | ASR 文本或 AI 回复文本 | 无 |
| asr_confidence | decimal | 5,4 | 可空 | `NULL` | ASR 总置信度，AI turn 为空 | 无 |
| asr_metrics_json | json | - | 可空 | `NULL` | 词级置信度、语速、停顿、filler 等指标 | 无 |
| audio_object_key | varchar | 512 | 可空 | `NULL` | S3 / MinIO 音频对象 key | 无 |
| audio_mime_type | varchar | 128 | 可空 | `NULL` | 音频 MIME | 无 |
| audio_duration_ms | int | - | 可空 | `NULL` | 音频时长，毫秒 | 无 |
| created_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 创建时间 | 无 |
| updated_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 更新时间 | 无 |
| deleted_at | datetime(3) | - | 可空 | `NULL` | 软删除时间 | 无 |

必要索引：

| 索引名 | 字段 | 说明 |
|---|---|---|
| `uk_conversation_turns_session_turn_index` | `(session_id, turn_index)` | 保证回放和上下文顺序唯一 |
| `uk_conversation_turns_session_client_turn` | `(session_id, client_turn_id)` | 用户录音上传重试幂等，MySQL 允许多个 `NULL` |
| `idx_conversation_turns_session_speaker` | `(session_id, speaker)` | 报告生成时快速读取用户发言 |

必要约束：

- 用户 turn 上传后先进入 `pending`。
- 用户确认后进入 `confirmed`，才参与上下文和报告评分。
- 用户重说时原 turn 标记为 `discarded`，不参与 LLM 上下文和评分。
- AI turn 创建时直接使用 `confirmed`。

## 6. `assessment_reports` 课后报告表

| 字段名 | 数据类型 | 长度 | 是否主键 / 非空 | 默认值 | 注释 | 索引 |
|---|---:|---:|---|---|---|---|
| id | varchar | 36 | 主键、非空 | 应用生成 UUID | 报告主键 | 主键索引 |
| session_id | varchar | 36 | 非空 | 无 | 对应练习会话 | 唯一索引 `uk_assessment_reports_session` |
| status | varchar | 32 | 非空 | `pending` | `pending` / `completed` / `failed` | 索引 `idx_assessment_reports_status_updated` |
| overall_score | int | - | 可空 | `NULL` | 总评分 | 无 |
| pronunciation_score | int | - | 可空 | `NULL` | 发音 / 可懂度评分 | 无 |
| fluency_score | int | - | 可空 | `NULL` | 流利度评分 | 无 |
| grammar_score | int | - | 可空 | `NULL` | 语法评分 | 无 |
| expression_score | int | - | 可空 | `NULL` | 表达自然度评分 | 无 |
| level_description | varchar | 128 | 可空 | `NULL` | 水平描述 | 无 |
| one_sentence_summary | text | - | 可空 | `NULL` | 一句话总结 | 无 |
| feedback_json | json | - | 可空 | `NULL` | 改进详情数组 | 无 |
| error_code | varchar | 64 | 可空 | `NULL` | 报告失败错误码 | 无 |
| error_message | varchar | 512 | 可空 | `NULL` | 报告失败提示 | 无 |
| created_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 报告任务创建时间 | 无 |
| updated_at | datetime(3) | - | 非空 | `CURRENT_TIMESTAMP(3)` | 报告更新时间 | 索引 `idx_assessment_reports_status_updated` |
| deleted_at | datetime(3) | - | 可空 | `NULL` | 软删除时间 | 无 |

必要索引：

| 索引名 | 字段 | 说明 |
|---|---|---|
| `uk_assessment_reports_session` | `(session_id)` | 一次练习只生成一份报告 |
| `idx_assessment_reports_status_updated` | `(status, updated_at)` | Worker 查找 pending / failed 报告和排查卡住任务 |

必要约束：

- 报告创建和 session 进入 `reporting` 必须在同一事务中完成。
- 报告完成后必须写入总分、4 项细分分、水平描述、一句话总结和 `feedback_json`。
- `feedback_json` MVP 只要求 1 条发音建议和 1 条语法 / 表达建议。
