# 后端模块详细设计

本文件为 MVP 极简版模块详细设计，只保留模块归属、功能清单、外部依赖、特殊规则 4 块内容。

## 1. 模块归属

| 模块 | 对应总体设计模块 | 所在层级 | 负责人 |
|---|---|---|---|
| Auth | Auth | 接口层 / 业务服务层 | 后端负责人，待定 |
| Scenario | Scenario Service | 业务服务层 | 后端负责人，待定 |
| Practice Session | Practice Session Service | 业务服务层 | 后端负责人，待定 |
| Conversation Orchestrator | Conversation Orchestrator | 应用层 | 后端负责人，待定 |
| Media | Media Service | 业务服务层 / 基础设施层 | 后端负责人，待定 |
| Assessment / Report | Assessment Service、Report Worker | 业务服务层 / 应用层 | 后端负责人，待定 |
| History | History Service | 业务服务层 | 后端负责人，待定 |
| Provider Clients | ASR / LLM / TTS Clients | 基础设施层 | 后端负责人，待定 |

## 2. 本模块功能清单

| 模块 | 本期功能点 |
|---|---|
| Auth | 创建匿名用户；恢复匿名用户；签发 7 天 JWT；请求中解析当前用户；校验用户只能访问自己的 session / report |
| Scenario | Seed 初始化 3 个固定场景；查询场景列表；查询开练确认详情；提供场景角色、步骤、开场白和 prompt 片段 |
| Practice Session | 创建练习；限制同一用户只有 1 个 `in_progress` session；保存用户 / AI turn；确认 transcript；废弃重说 turn；结束练习并进入 `reporting` |
| Conversation Orchestrator | 编排单轮链路：保存音频、ASR、创建 pending user turn、确认后拼接上下文、调用 LLM、调用 TTS、保存 AI turn、推进步骤 |
| Media | 生成对象 key；上传用户原始音频和 AI 合成音频；生成短期签名 URL；记录 MIME 和音频时长；历史删除时发起对象删除 |
| Assessment / Report | 读取已确认用户 turn；按 30/25/25/20 权重生成总分；处理 ASR 低置信降权；校验报告 JSON；写入报告状态；失败可重试 |
| History | 查询历史列表；查询单次练习 transcript；聚合练习次数、开口时长、用户词数、平均分、分数趋势 |
| Provider Clients | 封装 ASR / LLM / TTS 调用；统一超时、重试、错误码；支持 mock provider 兜底 demo |

## 3. 外部依赖

| 模块 | 依赖 |
|---|---|
| Auth | MySQL、JWT secret、密码哈希工具 |
| Scenario | MySQL seed、场景 JSON 配置 |
| Practice Session | MySQL、Scenario Service、RabbitMQ report publisher |
| Conversation Orchestrator | Practice Session Service、Scenario Service、Media Service、ASR Client、LLM Client、TTS Client |
| Media | S3 / MinIO、临时文件目录、可选音频转码工具 |
| Assessment / Report | MySQL、LLM Client、RabbitMQ、Celery、Pydantic report schema |
| History | MySQL、Assessment Report、Conversation Turns |
| Provider Clients | 第三方 ASR / LLM / TTS 服务、API key、mock 配置 |

## 4. 特殊规则

| 模块 | 特殊规则 |
|---|---|
| Auth | 后端只保存 `anonymous_secret_hash`；JWT 过期后必须用 `anonymous_id` + `anonymous_secret` 换新 token；业务接口均需 Bearer token |
| Scenario | MVP 只允许 `interview`、`restaurant`、`meeting`；不提供后台新增和编辑；AI 回复必须始终保持角色扮演 |
| Practice Session | `client_turn_id` 保证上传幂等；只有 `pending` user turn 可确认或废弃；重复确认同一 turn 返回已有 AI turn，不重复调用 LLM / TTS |
| Conversation Orchestrator | Router 不直接调用 ASR / LLM / TTS；TTS 失败时返回 AI 文本并允许继续；LLM 失败时可使用场景兜底追问 |
| Media | 单轮录音最长 60 秒，默认最大 20MB；音频对象不公开访问；日志不打印完整音频 URL |
| Assessment / Report | `asr_confidence < 0.65` 的 turn 默认不进评分；没有专用发音评测时不输出音素、重音、连读等细粒度结论；报告 JSON 必须通过 schema 校验 |
| History | 历史只展示当前用户数据；删除历史时软删除 DB 记录并异步删除音频对象；长期数据由已有表动态聚合 |
| Provider Clients | 调用失败最多重试 2 次；超时和第三方错误统一转换成全局错误码；demo 可切换 mock provider |
