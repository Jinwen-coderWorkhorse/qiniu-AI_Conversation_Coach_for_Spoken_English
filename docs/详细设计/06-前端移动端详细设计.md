# 前端 / 移动端详细设计

前端以 Web / PWA 为主，优先适配移动端浏览器，同时兼容桌面浏览器。MVP 不做营销落地页，首屏就是可开始练习的产品界面。

## 1. 页面与组件清单

| 页面 | 目标 | 主要组件 |
|---|---|---|
| 首页 | 打开即选择场景 | `AppShell`、`ScenarioGrid`、`ScenarioButton`、`HistoryDrawer`、`StatsSummary` |
| 开练确认页 | 用最少信息帮助用户开始 | `ScenarioHeader`、`TaskSteps`、`PrimaryActionButton` |
| 语音对话页 | 沉浸式按住说话对话 | `PracticeHeader`、`AiCurrentUtterance`、`RecentTranscript`、`PushToTalkButton`、`WaveformMeter`、`TranscriptReview`、`PracticeStatus` |
| 报告总览页 | 先给整体表现 | `OverallScoreRing`、`LevelDescription`、`OneSentenceSummary`、`ScoreDialGrid`、`ReportActions` |
| 改进详情页 | 给少量可执行建议 | `ImprovementCard`、`PracticeAgainButton` |
| 历史回看页 | 回看 transcript 和报告入口 | `TranscriptTimeline`、`SessionMeta`、`ReportLink` |

## 2. 路由定义

说明：路由中的 `[scenarioSlug]`、`[sessionId]` 是 Next.js 动态路由参数，不是运行时创建的文件夹，也不是前端持久化目录。页面通过参数调用后端接口恢复数据。

| 路由 | 页面 | 路由层级 | 说明 |
|---|---|---|---|
| `/` | 首页 | 一级 | 展示 3 个场景入口和侧边栏 |
| `/practice/[scenarioSlug]/start` | 开练确认页 | 二级 | `scenarioSlug` 为 `interview` / `restaurant` / `meeting` |
| `/practice/sessions/[sessionId]` | 语音对话页 | 二级 | 当前练习主页面，刷新可恢复 |
| `/reports/[sessionId]` | 报告总览页 | 二级 | 展示总分、水平描述和 4 个细分分 |
| `/reports/[sessionId]/improvements` | 改进详情页 | 三级 | 展示 1 条发音建议和 1 条语法 / 表达建议 |
| `/history/[sessionId]` | 历史回看页 | 二级 | 展示完整 transcript，提供报告入口 |

## 3. 页面接口关联

| 页面 | 调用接口 | 时机 |
|---|---|---|
| 全局启动 | `POST /auth/anonymous` | 首次进入、token 过期恢复 |
| 首页 | `GET /scenarios`、`GET /practice-sessions`、`GET /me/stats` | 页面加载、侧边栏打开 |
| 开练确认页 | `GET /scenarios/{slug}`、`POST /practice-sessions` | 页面加载、点击开始练习 |
| 语音对话页 | `GET /practice-sessions/{id}`、`POST /practice-sessions/{id}/user-turns`、`POST /practice-sessions/{id}/turns/{turn_id}/confirm`、`POST /practice-sessions/{id}/turns/{turn_id}/discard`、`POST /practice-sessions/{id}/end`、`GET /practice-sessions/{id}/events` | 刷新恢复、上传音频、确认、重说、结束、订阅进度 |
| 报告总览页 | `GET /practice-sessions/{id}/report`、`GET /practice-sessions/{id}/events` | 页面加载、报告 pending 时等待 |
| 改进详情页 | `GET /practice-sessions/{id}/report` | 页面加载 |
| 历史回看页 | `GET /practice-sessions/{id}`、`GET /practice-sessions/{id}/report` | 页面加载 |

## 4. 首页交互规则

- 首屏只展示产品名、引导文案和 3 个场景入口。
- 点击场景后进入 `/practice/[scenarioSlug]/start`，不弹二次任务选择。
- 左上角菜单打开侧边栏，侧边栏展示最近历史和长期数据。
- 侧边栏历史点击后进入 `/history/[sessionId]`。
- 首页加载时如果匿名身份不存在，先调用 `/auth/anonymous`。

## 5. 开练确认页交互规则

- 只展示场景名、一句话说明、预计时间和任务步骤。
- 点击“开始练习”后调用 `POST /practice-sessions`。
- 创建成功后跳转 `/practice/sessions/[sessionId]`。
- 如果开场白 TTS 失败，仍进入对话页，显示 AI 文本并允许用户开始。
- 如果返回 `SESSION_ALREADY_IN_PROGRESS`，提示用户继续当前练习或结束当前练习。

## 6. 语音对话页交互规则

### 6.1 录音

- 只支持按住说话，按下开始录音，松开发送。
- 按下 200ms 内显示录音态和波形。
- 单轮录音超过 60 秒自动停止并提示。
- 麦克风权限被拒绝时展示授权提示和重试入口。
- 录音中不允许同时点击结束练习。

### 6.2 Transcript 确认

- `/user-turns` 返回后展示识别文本、置信度提示、确认和重说。
- `needs_retry=true` 时文案提示“识别不太确定，建议重说一次”。
- 点击重说调用 discard，再回到 ready / recording。
- 点击确认调用 confirm，等待 AI 回复。

### 6.3 AI 回复

- AI 回复期间展示“AI 正在回应...”。
- REST confirm 返回后立即展示 AI 字幕和播放音频。
- 如果音频 URL 为空，展示文本并允许继续下一轮。
- 用户可以请求 AI 角色重复，但通过自然语言说出，不提供“让 AI 帮我”工具按钮。

### 6.4 结束练习

- 右上角提供弱化的结束按钮。
- 点击后二次确认，避免误触。
- 结束成功后进入报告等待或报告总览页。
- 报告 pending 时展示等待状态，并通过 SSE 或轮询恢复。

## 7. 报告页交互规则

### 7.1 报告总览页

- 总分和水平描述最突出。
- 4 个细分分只展示圆盘和分数，不展开具体原因。
- 按钮包括“查看改进建议”和“再练一次”。
- 报告 pending 时展示生成中状态。
- 报告 failed 时展示“报告生成失败，可稍后重试”，保留返回历史和再练入口。

### 7.2 改进详情页

- MVP 每次只展示 1 条发音建议和 1 条语法 / 表达建议。
- 建议内容包含问题说明、推荐表达、中文解释、复练句。
- “用这句话练一次”回到当前场景开练确认页或新建同场景练习。

## 8. 公共组件设计

| 组件 | 用途 | 统一规则 |
|---|---|---|
| `AppShell` | 页面框架 | 顶部仅保留必要导航和侧边栏入口 |
| `HistoryDrawer` | 历史与长期数据 | 默认收起，不抢占首页主任务 |
| `ScenarioButton` | 场景入口 | 展示场景名、summary、预计时间 |
| `PushToTalkButton` | 主语音按钮 | 大尺寸、底部固定、录音态明显 |
| `WaveformMeter` | 音量波形 | 仅录音态展示，避免静态干扰 |
| `TranscriptReview` | 识别确认 | 确认和重说两个动作，低置信提示 |
| `ScoreRing` | 总分 / 细分分 | 报告页统一圆盘风格 |
| `ErrorToast` | 错误提示 | 统一使用全局错误 message，可重试时展示操作 |
| `LoadingState` | 等待状态 | 上传、识别、AI 回复、报告生成分别有清晰文案 |

## 9. 前端状态管理

`practiceSlice` 保存练习页复杂状态：

```text
sessionId
scenario
currentStepNo
turns
recordingState
pendingUserTurn
aiStatus
reportStatus
error
```

状态来源规则：

- REST 响应是最终数据来源。
- SSE 只更新进度状态，不直接替代最终结果。
- 浏览器本地只保存匿名身份、token 和可选当前 session ID；不保存 transcript、报告、分数和音频引用等业务数据。
- 页面刷新后通过 `GET /practice-sessions/{id}` 恢复 transcript 和当前步骤。
- 报告页刷新后通过 `GET /practice-sessions/{id}/report` 恢复状态。

## 10. 移动端适配规则

- 主语音按钮固定在底部安全区上方。
- Transcript 确认弹层不得遮挡底部主操作。
- 对话历史只默认展示最近 2-3 轮，可上滑查看。
- 报告页总分位于首屏上部，细分分和按钮在下方。
- 所有按钮文字必须在 320px 宽度下不溢出。
- 页面不使用复杂多列布局，桌面端可以提高内容最大宽度但不改变主流程。
